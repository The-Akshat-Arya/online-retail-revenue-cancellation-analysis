# Dataset Information

## Source

This project uses the **Online Retail** dataset from the UCI Machine Learning Repository.

The original dataset contains transaction records for a UK-based online retailer from:

- 1 December 2010
- 9 December 2011

December 2011 contains data only through 9 December and should be treated as a partial month.

## Repository Data Files

A 10,000-row sample of the cleaned sales dataset.
